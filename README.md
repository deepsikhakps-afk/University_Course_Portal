# 🎓 University Course Portal

## 📌 About the Project
University Course Portal is a web-based application designed to manage university courses and academic information. It provides an organized platform where students can explore available courses and view course details. The project aims to make course management easier and more efficient.

## ✨ Features
- View available university courses
- Access course details and information
- User-friendly interface
- Organized academic information
- Easy course navigation

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Project Structure
```text
University_Course_Portal/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run the Project
1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.

## 🎯 Objective
The main objective of this project is to provide a simple and organized platform for exploring university courses and accessing academic information.
